Machine code

The chip only understands bytes. An assembler turns readable instructions into those bytes. Type an instruction, or pick one, and see exactly what the CPU will fetch.

What to notice

  • The first byte is always the opcode. It tells the decoder what to do and how many more bytes follow.
  • The 8051 has 111 instructions, encoded in 255 of the 256 possible opcodes (A5H is reserved).
  • Instructions are 1, 2 or 3 bytes long and take 1, 2 or 4 machine cycles. Only MUL and DIV take 4.
