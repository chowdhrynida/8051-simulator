The full app

The full simulator is a Python and tkinter program, built from scratch between August 2025 and March 2026. It was presented at the JIGNYASA College Fest as a tool that connects microcontroller theory with hands-on simulation.

Simulator core

Emulates the 8051 architecture: accumulator, B register, PC, SP, DPTR and the PSW flags, four register banks, timer/counter and interrupt control, and a serial/UART module.

Run a program step by step or continuously, and follow it in a live execution trace.

Circuit designer

A virtual circuit board where the 8051's ports connect to an LCD, LEDs, a 7-segment display, stepper and DC motors, an HC-SR04 distance sensor and passive components.

Upload your code and watch the hardware respond in real time.

Virtual oscilloscope

A dual-channel CRO with DUAL and ADD modes, full vertical and horizontal controls and a trigger section.

It measures frequency automatically from the live waveform, so you can check a timer's output the way you would on a bench.

Get the full simulator

Download the Windows app, or run it from source with Python 3. tkinter comes with Python on Windows and macOS.

Windows may show "Windows protected your PC" the first time because the app is not signed. Choose More info, then Run anyway.
