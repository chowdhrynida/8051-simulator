    U2 Serial port (UART)

    Nothing sent yet.

    Set up Timer 1 and SCON, then write a byte to SBUF.

    Choose the UART example to send HELLO. A bit lasts 32 x (256 - TH1) machine cycles, so TH1 = FDH gives 9600 baud. Receiving needs REN set (MOV SCON,#50H), and Timer 1 must be running.
