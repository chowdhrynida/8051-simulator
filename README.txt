McuLab 8051 Simulator - App (PWA) package
==========================================
1. Ye poora folder kisi bhi free hosting par upload karo (https zaroori hai):
   - Netlify Drop: https://app.netlify.com/drop  (folder drag-drop)
   - GitHub Pages / Cloudflare Pages / Vercel
2. Mila hua link Chrome (Android / Windows / Mac) me kholo.
3. Address bar me "Install" icon (ya menu -> Install app / Add to Home screen) dabao.
4. App ban jayegi: alag window, home-screen icon, aur internet ke bina bhi chalegi.

Local test: is folder me terminal kholo -> python3 -m http.server 8080 -> browser me http://localhost:8080
Note: file par double-click (file://) karne par bhi simulator chalta hai, bas install option nahi aata.
